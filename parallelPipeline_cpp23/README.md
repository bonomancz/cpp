
PARALLEL PIPELINE C++23
-----------------------

About:
-----------------------

Parallel pipeline demonstrates the relationship and flow of data processing through a producer, worker, and consumer, where all three components are represented in a separate working thread.<br /><br />
The program is based on the thread-safe wrapper std::queue, which provides a robust mechanism against data-race conditions and solves the issue of multithreaded processing of std:queue.
